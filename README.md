# Notch for Windows

شريط "نوتش" ديناميكي أعلى الشاشة لويندوز، مع أدوات العناية بالحاسوب.

## التثبيت
نزّل أحدث ملف `Notch-Setup-x.y.z.exe` من صفحة [Releases](../../releases/latest) وشغّله مرة واحدة.
البرنامج يعمل تلقائياً مع تشغيل ويندوز، ويحدّث نفسه تلقائياً عند صدور إصدار جديد.

## المميزات
- موسيقى + كلمات متزامنة، طقس، تاريخ (ميلادي/هجري)، مؤقّت، تنبيهات (شحن، بطارية، فتح تطبيق)
- ربط Claude Code: سماح/رفض من النوتش وإشعار انتهاء المهمة
- العناية بالحاسوب: درجة صحة الجهاز، تسريع الذاكرة، تنظيف التخزين، الملفات الكبيرة، العمليات، برامج بدء التشغيل، حالة Defender وتحديث ويندوز، أدوات سريعة

## إصدار نسخة جديدة
غيّر `version` في `package.json` ثم:
```
git tag v1.2.0 && git push --tags
```
GitHub Actions يبني المثبّت وينشره، والتطبيقات المثبّتة تتحدّث تلقائياً.
